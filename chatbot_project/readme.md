# AI Chatbot with Streamlit + LangGraph
* A simple AI chatbot application built using Streamlit for the frontend and LangGraph/LangChain for the backend.
The chatbot supports streaming responses and maintains conversation history using Streamlit session state.


# Features

* Real-time AI response streaming
* Chat history persistence
* LangGraph/LangChain backend integration
* Clean Streamlit chat UI
* Thread-based conversation handling
