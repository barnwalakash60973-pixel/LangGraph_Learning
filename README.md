# LangGraph_Learning

A personal learning repository for exploring and building AI workflows using LangGraph.

This repository contains hands-on examples, mini projects, and workflow implementations covering:

- Basic LangGraph workflows
- State management
- Conditional routing
- Multi-step AI pipelines
- Multi-agent systems
- Prompt chaining
- LLM orchestration
- Feedback loops
- AI automation projects

## Projects Included

- BMI Workflow
- Simple LLM Workflow
- Prompt Chaining
- Batman Workflow
- UPSC Essay Workflow
- Quadratic Equation Solver
- Review Reply Generator
- AI Tweet/X Post Generator
- More LangGraph experiments and workflows
